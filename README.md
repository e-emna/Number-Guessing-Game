🎲 Number Guessing Game
📌 Overview
This is a simple Python-based number guessing game.
The program randomly selects a number within a given range, and the player tries to guess it.
It provides hints (higher/lower) until the correct number is guessed.

⚙️ Prerequisites
Make sure you have the following installed:

Python 3.x

A terminal or command prompt to run the script (e.g., vscode terminal)

🚀 How to Run
Clone the repository

bash

git clone https://github.com/e-emna/Number-Guessing-Game.git
cd Number-Guessing-Game
Run the script

bash

python NumberGuessingGame.py


🎮 How to Play
The program will ask you to guess a number between 1 and 100.

Enter your guess in the terminal.

The game will tell you if your guess is too high or too low.

Keep guessing until you find the correct number.

The program will display the number of attempts you made.
